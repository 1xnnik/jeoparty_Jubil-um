# Songrunde

Vier eigene MP3-Dateien als song-1.mp3 bis song-4.mp3 hier ablegen. Im Editor die jeweilige Antwort (Titel und Interpret) ergänzen. Die Dateien werden erst nach Klick auf Play wiedergegeben, ohne Autoplay. Das fünfte Feld ist ein Musik-Bonus ohne MP3.

Alternativ MP3s im Editor direkt einbetten (max. 2 MB je Datei, gemeinsames Browser-Speicherlimit beachten). Größere Dateien immer hier ablegen. Keine MP3-Dateien wurden mitgeliefert.
